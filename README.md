# Academy_Project-

Academic Website for Kalaivani Sainik Academy, built with Next.js, React, TypeScript, and SQLite.

## Overview
A comprehensive web portal for Kalaivani Sainik Academy featuring course details, admission registration, interactive elements, lead capture, and responsive design.

## Tech Stack
- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** CSS & Modern UI Components
- **Database:** SQLite (`better-sqlite3`)
- **Graphics:** Three.js

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Initialize database (if needed):**
   ```bash
   node scripts/init-db.js
   node scripts/seed-db.js
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
